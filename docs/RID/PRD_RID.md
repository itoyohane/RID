# RID MVP 产品需求文档

## 1. 产品概述

**产品名称：** RID  
**产品形态：** Windows 桌面工具  
**一句话定位：** 以一个主应用为入口，绑定需要同时打开和临时关闭的其他应用。

## 2. 背景与问题

用户启动某个应用时，经常还需要手动打开配套软件、关闭冲突或暂时不需要的软件，并在主应用退出后恢复此前关闭的软件。普通快捷方式只能启动单个应用，脚本方案又要求用户维护路径、进程名与恢复逻辑。

RID 让用户通过可视化表单创建一个 Bind Apps 模块，并以主应用名称组织和管理这些模块。

## 3. 目标用户

- 需要固定应用组合的 Windows 用户。
- 不希望编写脚本或维护命令行配置的普通用户。
- 希望减少重复打开、关闭和恢复操作的开发者、创作者及知识工作者。

RID 不按游戏、办公或专注等用途限制用户。

## 4. 核心概念

每个 **Bind Apps** 模块包含：

- **主应用：** 模块名称、启动入口和生命周期依据。
- **同时打开应用：** 启动主应用时一并打开。
- **临时关闭应用：** 启动主应用前尝试正常关闭。
- **恢复规则：** 主应用退出后，只重新打开本次成功关闭且启动前正在运行的应用。

RID 不在主应用退出后关闭本次自动打开的应用。

## 5. MVP 目标

- 首页直接进入“新增选项”表单。
- 用户能通过模糊搜索找到并选择应用。
- 用户能在两分钟内创建第一个 Bind Apps 模块。
- 保存后的模块以主应用名称出现在侧栏，并可继续编辑。
- 用户可在指定位置为模块生成可直接运行的 Windows 快捷方式。
- 试运行能够提前展示绑定将执行的操作。

## 6. 核心用户流程

1. 用户打开 RID，默认进入“新增选项”。
2. 用户选择一个主应用。
3. 用户按需添加需要同时打开的应用。
4. 用户按需添加需要临时关闭的应用。
5. 用户执行试运行，检查应用是否可找到。
6. 用户保存 Bind Apps。
7. 用户选择文件夹，RID 生成“主应用名 · RID”快捷方式。
8. 侧栏出现以主应用名称命名的模块。
9. 用户双击快捷方式，RID 在后台执行关闭、打开和主应用启动操作。
10. 主应用退出后，RID 恢复本次成功关闭的应用并结束后台进程。
11. 用户点击侧栏模块可继续修改配置；原快捷方式自动使用最新配置。

## 7. 信息架构

### 7.1 侧边栏

- RID Logo。
- 第一项固定为“新增应用”。
- “Bind Apps”分组，列出已保存模块。
- 每个模块显示主应用图标和主应用名称。
- 底部保留设置入口。

### 7.2 新增选项页

- 主应用选择区。
- 同时打开应用列表。
- 临时关闭应用列表。
- 固定恢复规则说明。
- 试运行按钮。
- 保存 Bind Apps 按钮。

### 7.3 已保存模块页

结构与新增选项页一致，标题使用主应用名称，保存操作改为“保存更改”。

### 7.4 快捷方式创建反馈

- 保存成功后提供“选择位置并创建”操作。
- 使用 Windows 文件夹选择器，不预设只能保存到桌面。
- 成功后展示生成文件的完整路径。
- 取消选择目录不影响已保存的 Bind Apps。

## 8. 应用搜索

- 支持应用名称的完整和部分匹配。
- 支持可执行文件路径片段匹配。
- 支持英文简称和常用别名。
- 支持非连续字符的模糊匹配。
- 匹配结果按相关程度排序。
- 无结果时提供更换名称、路径或拼音的提示。

## 9. 功能规则

- 一个模块只能有一个主应用。
- 主应用不能同时出现在打开或临时关闭列表。
- 同一应用不能同时属于打开和临时关闭列表；重新添加时自动移动到新分组。
- 已在当前分组中的应用不会重复出现。
- 保存前必须选择主应用。
- 清除主应用后，试运行和保存按钮进入禁用状态。
- 快捷方式只保存 Bind Apps ID；编辑模块后无需重新生成。
- 快捷方式目标为 RID，启动参数为对应 Bind Apps ID，图标使用主应用图标。

## 10. 安全与恢复

- 默认请求应用正常退出，不强制结束进程。
- 只恢复启动前正在运行且被 RID 成功关闭的应用。
- 不恢复启动前未运行的应用。
- 恢复失败只通知一次，不无限重试。
- 不控制 Windows 核心进程、系统服务或安全软件。

## 11. 本版不做

- 不按游戏、办公、直播等用途提供固定分类。
- 不提供多级连锁、条件触发或脚本编辑。
- 不监听从主应用原始快捷方式或其他入口启动的主应用。
- 不实现账号、云同步与多人共享。
- 不支持 macOS 和 Linux。

## 12. MVP 验收标准

- 启动后默认显示空白“新增选项”页。
- 侧栏 Logo 下第一项为“新增应用”。
- 主应用、同时打开应用和临时关闭应用均可通过模糊搜索选择。
- 保存后侧栏以主应用名称显示模块。
- 已保存模块可再次打开并修改。
- 用户可选择任意有写入权限的文件夹生成 `.lnk` 快捷方式。
- 双击生成的快捷方式时 RID 不显示主窗口，并按“临时关闭 → 同时打开 → 主应用”顺序执行。
- 主应用退出后，只恢复本次由 RID 成功关闭的应用，随后 RID 后台进程退出。
- 修改同一 Bind Apps 后，已有快捷方式执行最新配置。
- 试运行和保存流程均有明确结果反馈。
- 主应用缺失时不允许试运行或保存。
